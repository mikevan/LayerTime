# LayerTime face readability overlay

Extract this ZIP directly into the LayerTime project root and overwrite matching files.

Changes:
- Main ALT / HDG / WX / GPS labels increased from Montserrat 14 to Montserrat 18.
- ALT and WX use LayerTime gold.
- HDG uses teal.
- GPS uses bright green.
- Side data regions widened slightly for readability.
- GPS fix display changed from `12 SAT` to compact `3D 12` style.
- Seconds removed from the watch face.
- AM/PM removed from the watch face.
- 12/24-hour preference still controls the numeric hour format.
- Existing owl, time/date positions, footer, settings gesture, GPS data, and settings wiring are preserved.
