# LayerTime GPS Page Overlay

Extract this ZIP directly into the LayerTime project root and overwrite matching files.

## What this increment adds

- Tap the green GPS block on the watch face to open a dedicated GPS page.
- Live latitude and longitude to six decimal places.
- Live altitude using the selected unit system.
- Satellite count.
- HDOP.
- Speed.
- Course over ground when moving.
- Back button returns to the LayerTime watch face.
- GPS page refreshes continuously while open.

## Preserved face changes

- Large colored ALT / HDG / WX / GPS data.
- No seconds or AM/PM display.
- Footer uses Montserrat 20 at Y=455.
- Existing Settings long-press remains intact.

## Build note

Do not delete `.pio` yet. The current working LVGL SVG/ThorVG patches are still stored there.
