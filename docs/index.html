Install LayerTime

Counter-intrusion and resilient-communications firmware for the LilyGo T-Watch Ultra.
Flash it from this page · no toolchain, no account
T-WATCH ULTRA ONLY ESP32-S3 · 16 MB CHROME OR EDGE USB-C DATA CABLE

Plug the watch in first. You'll be asked to pick its serial port.

Flashed it, stuck on something, or just want to show it off? The project lives in LayerLand on Discord.
This browser can't flash. Installing over USB needs WebSerial, which only Chrome and Edge implement — Firefox and Safari have no equivalent, and neither does any browser on iOS. Open this page in Chrome or Edge on a desktop, or build from source instead.
This erases the watch. Installing writes a fresh bootloader, partition table and application, so anything already on the device — including another firmware's saved settings — is gone. Nothing on the SD card is touched.

If it won't connect

The Ultra talks over the ESP32-S3's native USB rather than a separate serial chip, so the automatic reset-into-download-mode that works on most boards is unreliable here. If the port doesn't appear, or the install fails immediately, put the watch into download mode by hand and try again:

  1. Unplug the watch.
  2. Hold the lower side button while you plug the USB-C cable back in.
  3. Keep holding for a couple of seconds after it's connected, then release.
  4. Click Connect & Install again and pick the port.

The port shows up as USB ID 303A:8227. If it still doesn't appear, it is almost always the cable — a great many USB-C cables carry power only. LilyGo's own download-mode notes cover the stubborn cases.

After it's flashed

The watch reboots into the face on its own. A few things worth knowing before you go looking for them:

  • Both radios start off, every boot. That's deliberate, not a bug — LoRa is opt-in from Settings each session, and MeshCore and Meshtastic are mutually exclusive because there's one physical SX1262.
  • Mesh messaging is new and lightly tested. The Meshtastic implementation is hand-rolled and the delivery-state, retry and PKC paths have not yet been exercised against a wide range of peers. Treat it as promising rather than proven, and please report what breaks.
  • Maps need an SD card. Tiles go at /maps/<style>/<z>/<x>/<y>.png — 256 px, 8-bit palette, XYZ scheme. Prebuilt regional bundles come from Oxed's tile downloader. The card must be FAT32; exFAT mounts on a computer and then silently fails on the watch.
  • Squachify swaps the owl for Squachy, by The Talking Sasquach. Put a 320 px-tall, 8-bit palette PNG with no alpha channel at /assets/squach.png on the card and turn it on in Settings.
  • Recon only listens. No injection, no association, no transmitting. Detections are indicators drawn from public radio traffic, not proof of anything.

Or build it yourself

Everything is in the repo. It builds against pioarduino, the community fork of platform-espressif32 — platformio.ini pins it, so you get the fork either way. Easiest route is VS Code with the pioarduino IDE extension: open the folder, let it fetch, and upload over USB. The first fetch pulls the ESP32 toolchain and about ten libraries and takes a while; after that it's quick.

git clone https://github.com/mikevan/LayerTime.git
cd LayerTime
pio run -t upload

default_envs = twatch_ultra is already set, so there's nothing to configure.
