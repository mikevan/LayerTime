# Decide what happens to MeshCore

Deferred until Meshtastic was finished so both could be judged side by side on real traffic. Meshtastic is now done, so the decision is live.

The options as they stood: keep both as-is (mutually exclusive, one SX1262), build the shared abstraction that was deliberately not built, or drop one.

Worth noting what MeshCore currently gives that Meshtastic does not: signed Ed25519 identity, and a much simpler protocol surface.
