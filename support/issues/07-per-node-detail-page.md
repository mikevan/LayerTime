# Meshtastic: per-node detail page

MUI parity gap. Tapping a node goes straight to a DM thread; there is no way to see everything known about it.

Available per node already: long/short name, hops, RSSI/SNR, age, battery/voltage/utilisation, position, whether a public key is held, and last-heard channel. That is a page's worth of information with nowhere to show it.

Related: tapping a map marker should probably land here too.
