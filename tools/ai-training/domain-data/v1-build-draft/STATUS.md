# Superseded construction draft — never trained

This draft was preserved, not admitted. Its first manifest accidentally hashed the console log while that log was still being written, so integrity validation correctly rejected it. The final version excludes console logs from the data manifest. Source-grounded questions were also corrected to supply the retrieved fact and citation metadata in the input, rather than expecting a model to invent an unseen page or source hash. Ontology questions now include their declared entry. These changes occurred before any model training or inference on this corpus.

Use the sibling v1 directory and its independent audit for the review candidate. Do not count this duplicate draft as additional source coverage or training examples.
